# FitLog

FitLog is a dark workout library. Pick a lift, read how to do it, and log it into today's plan or save it for later.

## Technologies

- Next.js (App Router)
- React
- Tailwind CSS
- DaisyUI

Workout data comes from the FitLog API.

## Features

- Browse twelve workouts in a responsive library, with photos, muscle tags, equipment, duration, calories, and rating.
- Open a workout for the full description, specs, and step-by-step instructions.
- Add a lift to today's plan or save it for later. The navbar counts update, and a toast confirms the action.
- Review My Plan with exercise, minute, and calorie totals, switch between Today's Plan and Saved, and sort by duration, calories, or rating.
- Mark a planned workout as done, remove a workout, and land on a 404 page when a route does not exist.
